# Перевірка перед передачею

Дата: 19.11.2026.

- `npm run check`: синтаксис сервера та обох клієнтських скриптів перевірено.
- `npm test`: 7 тестів пройшли. Перевірено серверний розрахунок ціни, невалідні кошики, приватні маршрути, вхід, розділення токенів входу й сесії, історію, PDF, зміну статусів, збереження після перезапуску та AES-256-GCM (включно з відмовою для іншого ключа й пошкодженого файла).
- Browser smoke у Microsoft Edge headless: пошук двома абетками, порожня видача, категорії, сортування, пагінація, обране після перезавантаження, кошик і кількість, оформлення та реквізити, прямі URL, збільшення ілюстрації, прихований вхід, 339 рядків виписки, CSV, статуси, вихід та повторне оформлення.
- Відсутній горизонтальний скрол сторінки на ширинах 320, 390, 768, 1024 і 1440 px. Таблиці адмінки мають власний горизонтальний скрол. Вітрину, мобільну версію, оформлення та адмінку переглянуто на знімках екрана.
- Імпорт: 235 унікальних товарів, 339 операцій. Надходження, списання й залишок після кожної операції звірені з PDF без розбіжностей.
- SHA-256 вихідного PDF та збереженого оригіналу збігається: `1430bf3bdb2c8135029622170c75bf30680b5db65dbb18c80be1bdc10ae287c3`.
- Початковий репозиторій doma не змінений.

Після оновлення фото: всі 235 позицій мають локальні WebP-фотографії з перевірених сторінок Rozetka. Перевірено HTTP-статус вихідних зображень, формат, розміри, наявність усіх локальних файлів та відповідність типів товарів на контактних аркушах. Для кількох варіантів однієї категорії використовуються однакові фото. Джерела й непідтверджені відмінності збережені у маніфесті; точний артикул не встановлюється лише за загальною назвою з таблиці.

Docker engine у середовищі відсутній, тому контейнер не збирався. Сервер перевірено локально, а не на віддаленому Railway.

Для публічного GitHub створений зашифрований пакет історії. Ключ і незашифровані вихідні файли не включені до коміту. Після розшифрування JSON та обидва PDF побайтово/структурно порівняні з локальними джерелами.

Необов’язковий браузерний тест вимагає Playwright і встановлений Edge. Вкажіть `PREVIEW_URL` запущеного тестового сервера та, для перевірки адмінки, `PREVIEW_ADMIN_PASSWORD`. Тест створює замовлення, тому використовуйте окремий `ORDERS_FILE` у тимчасовій папці, не бойову систему.
